### 🌐 GitHub Pages 배포 방식 안내

  현재 저장소(b4_1)에서도 GitHub Pages 배포가 매우 간단하게 가능합니다:

  • b4_1 저장소 설정(Settings) ➔ Pages ➔ Branch를 main으로 설정 후 Save
  • 배포 완료 시 https://ntt65.github.io/b4_1/ 주소로 웹사이트가 공개됩니다!

  │ 📌 참고: 만약 반드시 https://ntt65.github.io (뒤에 /b4_1이 없는 주소)로 제출해야 하는 조건이 있다면, 나중에 파일들을 이사시킬 필요 없이 GitHub에서 저장소 이름(Repository
  Name)만
  │ 변경하거나 원격 주소(Remote URL)만 변경하면 1초 만에 해결됩니다.

  따라서 지금 디렉토리에서 바로 1단계(index.html 시맨틱 구조 작성)부터 시작하시면 됩니다!
